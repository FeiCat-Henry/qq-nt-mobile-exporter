# 逐步操作说明

按顺序做，全程大约 5 分钟。假设：手机已 root、电脑装了 adb 和 Python。

## 0. 一次性的准备

```bash
# 1) 下载与手机 ABI 一致的 frida-server（一般 arm64）
#    https://github.com/frida/frida/releases
#    版本要和电脑端一致: pip install -U frida-tools

adb push frida-server /data/local/tmp/frida-server
adb shell su -c "chmod 755 /data/local/tmp/frida-server"

# 2) 输出目录（放在 QQ 自己的外部目录，属主天然正确）
adb shell su -c "mkdir -p /sdcard/Android/data/com.tencent.mobileqq/files/qqplain"
```

## 1. 启动 frida-server

```powershell
# Windows：让 adb 一直挂着，进程才不会立刻消失
Start-Process -FilePath adb -ArgumentList 'shell su -c "/data/local/tmp/frida-server -l 0.0.0.0:27042"' -WindowStyle Hidden
adb forward tcp:27042 tcp:27042
```

```bash
# Linux / macOS
adb shell su -c "/data/local/tmp/frida-server -l 0.0.0.0:27042" &
adb forward tcp:27042 tcp:27042
adb shell su -c "pidof frida-server"     # 确认在跑
```

> `su -c "nohup ... &"`、`sh start.sh` 都会失败（进程起来就没了）；只有 adb 前台挂着这一种稳定。
> 收尾：`adb shell su -c "kill -9 $(pidof frida-server)"`。

## 2. 让 QQ 自己导出明文库

```bash
cd mobile
python run_frida_export.py            # 会 force-stop 后正常启动 QQ，再 attach
python run_frida_export.py --no-restart   # 不想重启 QQ 时用这个
```

脚本做的事：`am force-stop` → `am start SplashActivity` → 找 pid → `dev.attach(pid)` → 注入 JS → 每 5 秒统计进度，核心库到齐就提前结束。

**注意不要用 spawn**：本机 `dev.spawn()` 会超时；即使 spawn 成功，QQ 也会停在后台上不打开数据库。

### 想多拿两样东西时，手机上配合点一下

| 想要 | 手机上做什么 |
|---|---|
| 群名 + 群成员昵称 | 点「联系人 → 群聊」，让 QQ 打开 `group_info.db` |
| 好友昵称（更多） | 启动即加载，一般已含 |
| 消息全文索引 | 基本不需要（正文在 `nt_msg.db` 里） |

## 3. 拉回电脑

```bash
adb pull /sdcard/Android/data/com.tencent.mobileqq/files/qqplain ./qqplain
```

确认是**明文**：文件头应该是 `SQLite format 3\0`

```bash
python -c "print(open('qqplain/nt_msg.db','rb').read(16))"
# b'SQLite format 3\x00'
```

## 4. 导出

图形界面（开浏览器，勾会话、选格式）：

```bash
python qq_exporter.py --nt-dir ./qqplain --uin 10000
```

批量：

```bash
python export_all.py --nt-dir ./qqplain --out ./out_html --fmt html
```

`--only` 只导指定会话，会话 key 可以从 `list_conversations` 的返回里看（好友是 `u_xxx`，群是群号）。

## 5. 收尾

```bash
adb shell su -c "rm -rf /sdcard/Android/data/com.tencent.mobileqq/files/qqplain"
```

电脑上的 `qqplain/` 是完整聊天记录明文，留意别误传/误提交。

---

## 排错

| 报错 | 处理 |
|---|---|
| `连接 frida-server 失败` | `adb forward` 有没有做；frida-server 版本与电脑 `frida` 是否一致 |
| 一直 `已导出 0 个库` | 手机停在欢迎/登录页时库不会打开；手动点开任意会话 |
| `[失败] xxx rc=1 table ... already exists` | 手机输出目录里有旧库，先 `rm -rf .../qqplain` 再跑 |
| `ModuleNotFoundError: frida` | `pip install -U frida-tools` |
| adb 命令全部挂住 | `Get-Process adb \| Stop-Process -Force` 后 `adb start-server` |
| 导出全空/全是「[无文本内容]」 | 用的不是本仓库改过的 `qq_exporter.py`（缺 `mobile_text()`） |
